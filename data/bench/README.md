# Bench captures

Raw serial output from a Spectra board, one frame per line, as sent by the stock firmware.

- `2026-11-18_spectra_16e_first_contact.txt`: first power-up after storage. 16-electrode mode (192 values per frame, opposition drive, 25 kHz), flex electrode ring in the 140 mm tank with little or no saline, USB serial at 115200 baud. Frame period 7.8 s. Useful as a parser fixture and a dry-tank reference, not as imaging data.
